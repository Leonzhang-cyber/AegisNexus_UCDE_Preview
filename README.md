# UCDE English UI Preview

Public, synthetic UI review preview for the Unified Cognitive Decision Engine.

This site supports preview role selection, scenarios, timezone display and a two-step confirmation demonstration. It does not authenticate users, grant actual permissions, create real approvals, write audit records or dispatch execution. All decision and evidence records are synthetic.

Only this preview is public. The main UCDE implementation repository remains private.

Open `index.html` in a browser or deploy using GitHub Pages. The included workflow publishes only `index.html`.
